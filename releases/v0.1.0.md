# v0.1.0 — Modal Stable Baseline

First stable Modal-native release for serving **Qwen3.8-27B NVFP4 + DFlash2 + SGLang** on a single **NVIDIA RTX PRO 6000 Blackwell Server Edition (96 GB)**.

## Validated stack

- GPU: `RTX-PRO-6000` × 1
- Target: `RadixArk/Qwen3.8-27B-NVFP4`
- Draft: `z-lab/Qwen3.8-27B-DFlash2`
- SGLang base: `lmsysorg/sglang:qwen38-27b`
- DFlash2 compatibility: repository `patch/sglang` backport
- Attention: FlashInfer
- KV cache: FP8 E4M3
- Native context limit: 262,144
- Speculative decoding: DFLASH, 8 draft tokens
- Mamba/GDN strategy: `extra_buffer`, FP32 state
- SGLang active requests: max 8
- Modal GPU replicas: hard-capped at 1

## Measured RTX PRO 6000 throughput

Observed steady-state server decode throughput from the validated concurrency sweep:

| Active requests | Aggregate decode throughput | Approx. per-user throughput |
| ---: | ---: | ---: |
| 1 | ~136 tok/s | ~136 tok/s |
| 2 | ~224 tok/s | ~112 tok/s |
| 4 | ~456 tok/s | ~114 tok/s |
| 8 | ~696 tok/s | ~87 tok/s |

The 8-request run was genuinely concurrent: SGLang reported `#running-req: 8`, `#queue-req: 0`, and `cuda graph: True` throughout the steady decode phase.

**4 concurrent requests** are the current latency/throughput sweet spot. **8 concurrent requests** maximize aggregate throughput on the single GPU.

The validated boot allocated approximately **958k shared KV tokens**. The 262,144 context value is a per-request upper bound; concurrent requests share the same KV pool.

## Modal deployment behavior

- Model snapshots are prepared on CPU and stored in a persistent Modal Volume.
- GPU runtime is offline from Hugging Face and mounts the model Volume read-only.
- Model shard integrity is checked before GPU allocation.
- DFlash2 runtime imports are checked while building the image.
- FlashInfer / SGLang compile cache uses a persistent Volume and is explicitly committed after startup/warmup.
- `min_containers=0`: GPU can scale to zero when idle.
- `max_containers=1`: demand cannot allocate a second RTX PRO 6000.
- SGLang runs in its own process session and shuts down gracefully.
- Benchmark SSE streams must end with `[DONE]` and report `usage.completion_tokens`; truncated streams fail hard.

## Run

Default long single-stream benchmark (4096 output tokens):

```bash
uv run modal run deploy/modal_app.py
```

Concurrency sweep:

```bash
uv run modal run deploy/modal_app.py --max-tokens 4096 --concurrency 1,2,4,8
```

Persistent endpoint:

```bash
uv run modal deploy deploy/modal_app.py
```

## Scope of this stable baseline

This release freezes the configuration that has completed real RTX PRO 6000 model loading, DFlash2 initialization, Mamba/KV allocation, prefill CUDA-graph capture, target/draft verify CUDA-graph capture, warmup, long decode, 1/2/4/8 concurrency, and graceful shutdown.

Experimental optimizations such as ReplaySSM speculative folding and text-only model-construction changes are intentionally **not** included in this stable baseline.
